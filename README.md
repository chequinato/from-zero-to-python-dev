## 🎯 Conceitos Principais - Guia Completo

### Python Language - Fundamentos

#### Tipos de Dados Primitivos
**int**: Números inteiros (ex: 42, -10, 0)
- Quando usar: Contagens, índices, IDs
- Exemplo: `idade = 25`, `contador = 0`

**float**: Números decimais (ex: 3.14, -0.5, 2.0)
- Quando usar: Cálculos, medições, porcentagens
- Exemplo: `preco = 19.99`, `temperatura = 36.5`

**str**: Strings de texto (ex: "Olá", 'Python')
- Quando usar: Texto, nomes, mensagens
- Exemplo: `nome = "João"`, `mensagem = f"Bem-vindo {nome}"`

**bool**: Booleanos (True, False)
- Quando usar: Flags, condições, estados
- Exemplo: `ativo = True`, `valido = False`

**None**: Ausência de valor
- Quando usar: Valores opcionais, inicialização
- Exemplo: `resultado = None`, `config = None`

#### Coleções

**list**: Lista mutável ordenada
- Quando usar: Coleções que precisam ser modificadas
- Exemplo: `numeros = [1, 2, 3]`, `nomes = ["Ana", "Bruno"]`
- Operações: append(), extend(), pop(), remove(), sort()
- Slicing: `lista[1:3]`, `lista[::-1]` (reverso)

**tuple**: Tupla imutável ordenada
- Quando usar: Dados que não devem mudar, retornos múltiplos
- Exemplo: `coordenadas = (10, 20)`, `cores = ("vermelho", "azul")`
- Unpacking: `x, y = coordenadas`

**dict**: Dicionário chave-valor
- Quando usar: Mapeamentos, configurações, dados estruturados
- Exemplo: `usuario = {"nome": "João", "idade": 25}`
- Métodos: get(), keys(), values(), items(), update()

**set**: Conjunto não ordenado de elementos únicos
- Quando usar: Remover duplicados, operações de conjunto
- Exemplo: `numeros_unicos = {1, 2, 3, 2, 1}` → {1, 2, 3}
- Operações: union(), intersection(), difference()

#### Estruturas de Controle

**if/elif/else**: Condicionais
- Quando usar: Tomar decisões baseadas em condições
- Exemplo:
```python
if idade >= 18:
    print("Maior de idade")
elif idade >= 16:
    print("Menor de idade com permissão")
else:
    print("Menor de idade")
```

**for**: Loops de iteração
- Quando usar: Iterar sobre sequências conhecidas
- Exemplo:
```python
for i in range(10):
    print(i)

for item in lista:
    processar(item)

for indice, valor in enumerate(lista):
    print(f"{indice}: {valor}")
```

**while**: Loops condicionais
- Quando usar: Iterar até uma condição ser falsa
- Exemplo:
```python
while contador < 10:
    print(contador)
    contador += 1
```

**break/continue**: Controle de loops
- break: Sai do loop completamente
- continue: Pula para a próxima iteração
- Exemplo:
```python
for numero in range(10):
    if numero == 5:
        break  # Para no 5
    if numero % 2 == 0:
        continue  # Pula pares
    print(numero)
```

#### Funções

**def**: Definição de funções
- Quando usar: Reutilizar código, organizar lógica
- Exemplo:
```python
def saudacao(nome):
    return f"Olá, {nome}!"

resultado = saudacao("Mundo")
```

**Parâmetros default**: Valores padrão
- Quando usar: Parâmetros opcionais
- Exemplo: `def criar_usuario(nome, ativo=True):`

***args**: Argumentos posicionais variáveis
- Quando usar: Número variável de argumentos
- Exemplo:
```python
def somar(*numeros):
    return sum(numeros)

soma = somar(1, 2, 3, 4, 5)
```

****kwargs**: Argumentos nomeados variáveis
- Quando usar: Número variável de argumentos nomeados
- Exemplo:
```python
def configurar(**kwargs):
    for chave, valor in kwargs.items():
        print(f"{chave}: {valor}")

configurar(host="localhost", porta=8080)
```

**lambda**: Funções anônimas
- Quando usar: Funções simples de uma linha, callbacks
- Exemplo:
```python
dobrar = lambda x: x * 2
numeros_dobrados = list(map(dobrar, [1, 2, 3]))
```

**decorators**: Modificadores de funções
- Quando usar: Adicionar funcionalidade a funções existentes
- Exemplo:
```python
def timer(func):
    def wrapper(*args, **kwargs):
        import time
        inicio = time.time()
        resultado = func(*args, **kwargs)
        print(f"Tempo: {time.time() - inicio}s")
        return resultado
    return wrapper

@timer
def processo_lento():
    time.sleep(1)
```

#### Orientação a Objetos

**class**: Definição de classes
- Quando usar: Modelar entidades do mundo real
- Exemplo:
```python
class Pessoa:
    def __init__(self, nome, idade):
        self.nome = nome
        self.idade = idade
    
    def apresentar(self):
        return f"Sou {self.nome}, {self.idade} anos"
```

**Herança**: Reutilizar código de classes existentes
- Quando usar: Especializar classes base
- Exemplo:
```python
class Animal:
    def falar(self):
        pass

class Cachorro(Animal):
    def falar(self):
        return "Au au!"
```

**Polimorfismo**: Mesma interface, diferentes implementações
- Quando usar: Tratar objetos diferentes de forma uniforme
- Exemplo:
```python
animais = [Cachorro(), Gato()]
for animal in animais:
    print(animal.falar())  # Cada animal fala diferente
```

**Encapsulamento**: Proteger dados internos
- Quando usar: Controlar acesso a atributos
- Exemplo:
```python
class Conta:
    def __init__(self):
        self._saldo = 0  # Atributo protegido
    
    @property
    def saldo(self):
        return self._saldo
```

**Métodos Especiais (dunder)**
- `__init__`: Construtor
- `__str__`: Representação string (para usuários)
- `__repr__`: Representação string (para desenvolvedores)
- `__eq__`: Comparação de igualdade
- `__len__`: Comportamento de len()
- `__getitem__`: Comportamento de indexação

#### Comprehensions

**List Comprehension**: Criar listas de forma concisa
- Quando usar: Transformar/filtrar dados
- Exemplo:
```python
# Tradicional
quadrados = []
for x in range(10):
    quadrados.append(x ** 2)

# Comprehension
quadrados = [x ** 2 for x in range(10)]

# Com filtro
pares = [x for x in range(10) if x % 2 == 0]
```

**Dict Comprehension**: Criar dicionários
- Quando usar: Criar mapeamentos
- Exemplo:
```python
quadrados = {x: x ** 2 for x in range(10)}
```

**Set Comprehension**: Criar conjuntos
- Quando usar: Criar conjuntos únicos
- Exemplo:
```python
unicos = {x % 3 for x in range(10)}
```

#### Iterators e Generators

**yield**: Criar generators
- Quando usar: Sequências grandes, lazy evaluation
- Exemplo:
```python
def gerador_numeros(n):
    for i in range(n):
        yield i

for numero in gerador_numeros(10):
    print(numero)
```

**Generator Expressions**: Comprehensions lazy
- Quando usar: Economizar memória em sequências grandes
- Exemplo:
```python
soma = sum(x ** 2 for x in range(1000000))
```

#### Tratamento de Erros

**try/except/finally**: Capturar exceções
- Quando usar: Tratar erros gracefully
- Exemplo:
```python
try:
    resultado = 1 / 0
except ZeroDivisionError:
    print("Não pode dividir por zero")
finally:
    print("Sempre executa")
```

**raise**: Lançar exceções
- Quando usar: Sinalizar erros
- Exemplo:
```python
def dividir(a, b):
    if b == 0:
        raise ValueError("Divisor não pode ser zero")
    return a / b
```

**assert**: Verificações de debugging
- Quando usar: Verificar invariantes
- Exemplo:
```python
assert idade >= 0, "Idade não pode ser negativa"
```

#### Context Managers

**with statement**: Gerenciar recursos automaticamente
- Quando usar: Arquivos, conexões, locks
- Exemplo:
```python
with open('arquivo.txt', 'r') as f:
    conteudo = f.read()
# Arquivo fechado automaticamente
```

### Biblioteca Padrão - Ferramentas Essenciais

#### collections
**Counter**: Contar elementos
- Quando usar: Contar frequências
- Exemplo: `Counter([1, 2, 2, 3, 3, 3])` → {3: 3, 2: 2, 1: 1}

**defaultdict**: Dicionário com valor padrão
- Quando usar: Evitar KeyError
- Exemplo:
```python
from collections import defaultdict
contagem = defaultdict(int)
contagem['a'] += 1  # Não lança KeyError
```

**OrderedDict**: Dicionário ordenado
- Quando usar: Preservar ordem de inserção (Python 3.7+ já é padrão)

**namedtuple**: Tuplas com campos nomeados
- Quando usar: Tuplas mais legíveis
- Exemplo:
```python
from collections import namedtuple
Ponto = namedtuple('Ponto', ['x', 'y'])
p = Ponto(10, 20)
print(p.x, p.y)
```

#### datetime
**date**: Data sem hora
- Quando usar: Trabalhar apenas com datas
- Exemplo: `hoje = date.today()`

**time**: Hora sem data
- Quando usar: Trabalhar apenas com horas

**datetime**: Data e hora
- Quando usar: Timestamps completos
- Exemplo: `agora = datetime.now()`

**timedelta**: Diferença de tempo
- Quando usar: Adicionar/subtrair tempo

```python
amanha = datetime.now() + timedelta(days=1)
```

**randint()**: Inteiro aleatório em range
- Quando usar: Números inteiros aleatórios
- Exemplo: `dado = random.randint(1, 6)`

**choice()**: Elemento aleatório de sequência
- Quando usar: Seleção aleatória
- Exemplo: `cor = random.choice(["vermelho", "azul"])`

**shuffle()**: Embaralhar lista
- Quando usar: Randomizar ordem

#### math
**sqrt()**: Funções matemáticas
- Quando usar: Cálculos matemáticos
- Exemplo: `raiz = math.sqrt(16)`

**pow()**: Potência
- Quando usar: Exponenciação
- Exemplo: `potencia = math.pow(2, 3)`

**sin(), cos(), tan()**: Funções trigonométricas
- Quando usar: Cálculos geométricos

#### re (Expressões Regulares)
**match()**: Buscar padrão
- Quando usar: Validar formatos, extrair dados
- Exemplo:
```python
email = re.match(r'[\w.]+@[\w.]+', texto)
```

**search()**: Buscar em qualquer posição
- Quando usar: Encontrar padrões
- Exemplo: `resultado = re.search(r'\d+', texto)`

**findall()**: Encontrar todas ocorrências
- Quando usar: Extrair múltiplos valores
- Exemplo: `numeros = re.findall(r'\d+', texto)`

#### itertools
**chain()**: Encadear iteradores
- Quando usar: Combinar múltiplas sequências
- Exemplo: `list(chain([1, 2], [3, 4]))` → [1, 2, 3, 4]

**combinations()**: Combinações
- Quando usar: Subconjuntos sem ordem
- Exemplo: `list(combinations([1, 2, 3], 2))` → [(1,2), (1,3), (2,3)]

**permutations()**: Permutações
- Quando usar: Todas ordens possíveis
- Exemplo: `list(permutations([1, 2, 3]))`

#### os
**path**: Manipulação de paths
- Quando usar: Trabalhar com sistema de arquivos
- Exemplo: `os.path.join('pasta', 'arquivo.txt')`

**listdir()**: Listar diretório
- Quando usar: Listar arquivos
- Exemplo: `arquivos = os.listdir('.')`

#### sys
**argv**: Argumentos de linha de comando
- Quando usar: Scripts CLI
- Exemplo: `argumentos = sys.argv`

**path**: Caminho do Python
- Quando usar: Configurar imports

### Arquitetura

#### SOLID
**S**: Single Responsibility - Uma classe, uma responsabilidade
**O**: Open/Closed - Aberto para extensão, fechado para modificação
**L**: Liskov Substitution - Substituibilidade de subclasses
**I**: Interface Segregation - Interfaces pequenas e específicas
**D**: Dependency Inversion - Depender de abstrações

#### Design Patterns
**Singleton**: Uma única instância
**Factory**: Criar objetos sem especificar classe exata
**Decorator**: Adicionar funcionalidade dinamicamente
**Observer**: Notificar mudanças a observadores
**Strategy**: Algoritmos intercambiáveis

#### Arquitetura Hexagonal
**Ports**: Interfaces para comunicação externa
**Adapters**: Implementações de ports
- Quando usar: Desacoplar lógica de infraestrutura

#### ABC
**Abstract Base Classes**: Definir interfaces formais

### Recursos Avançados da Linguagem

#### Decorators Avançados
**@staticmethod**: Método que não precisa de instância
- Quando usar: Funções utilitárias da classe
- Exemplo:
```python
class Matematica:
    @staticmethod
    def somar(a, b):
        return a + b

resultado = Matematica.somar(2, 3)
```

**@classmethod**: Método que recebe a classe como primeiro argumento
- Quando usar: Factory methods, alternativas de construtor
- Exemplo:
```python
class Pessoa:
    @classmethod
    def criar_anonimo(cls):
        return cls("Anônimo", 0)
```

**@property**: Getter para atributos
- Quando usar: Acesso controlado a atributos
- Exemplo:
```python
class Circulo:
    def __init__(self, raio):
        self._raio = raio
    
    @property
    def raio(self):
        return self._raio
    
    @raio.setter
    def raio(self, valor):
        if valor < 0:
            raise ValueError("Raio não pode ser negativo")
        self._raio = valor
```

**@functools.lru_cache**: Cache de resultados
- Quando usar: Otimizar funções caras
- Exemplo:
```python
from functools import lru_cache

@lru_cache(maxsize=128)
def fibonacci(n):
    if n < 2:
        return n
    return fibonacci(n-1) + fibonacci(n-2)
```

**@functools.wraps**: Preservar metadados de funções
- Quando usar: Criar decorators
- Exemplo:
```python
from functools import wraps

def meu_decorator(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        return func(*args, **kwargs)
    return wrapper
```

#### Metaclasses
**type**: Criar classes dinamicamente
- Quando usar: Metaprogramação, frameworks
- Exemplo:
```python
class MetaSingleton(type):
    _instances = {}
    def __call__(cls, *args, **kwargs):
        if cls not in cls._instances:
            cls._instances[cls] = super().__call__(*args, **kwargs)
        return cls._instances[cls]

class Singleton(metaclass=MetaSingleton):
    pass
```

#### Descriptors
**__get__, __set__, __delete__**: Comportamento de atributos
- Quando usar: Validação, caching, computed properties
- Exemplo:
```python

    def __init__(self, nome):
        self.nome = nome
    
    def __get__(self, obj, objtype):
        return obj.__dict__.get(self.nome)
    
    def __set__(self, obj, valor):
        if not isinstance(valor, int):
            raise TypeError("Deve ser inteiro")
        obj.__dict__[self.nome] = valor

class Pessoa:
    idade = Validador('idade')
```

#### Context Managers Customizados
**__enter__, __exit__**: Criar context managers

```python
    pass
```
